# Rancher Brand Atomic System

This directory is the machine-readable source of truth for Rancher's verbal and visual identity.

- `agent/verbal/` contains positioning, audiences, messaging, differentiation, concepts, and voice.
- `agent/visual/` contains visual tokens, assets, component guidance, and motion rules.
- `human/` is reserved for human-only source material and is ignored by BrandKit MCP.
- `magic_trick.md` must be authored and maintained by a human; BrandKit MCP serves it verbatim.

The canonical implemented website remains the Astro source under `src/` and `public/`. Update this system when approved brand decisions change.
