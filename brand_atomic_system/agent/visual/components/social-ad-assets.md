# Social ad asset system

A Rancher social concept is complete only when it has four independently composed exports: 1200×630, 1080×1080, 1080×1350, and 1080×1920. Keep all essential text, logos, qualifiers, URLs, and drawn CTAs inside these house safe zones:

- 1200×630: x 120–1080, y 63–567.
- 1080×1080: x 108–972, y 108–972.
- 1080×1350: x 108–972, y 135–1148.
- 1080×1920: x 108–864, y 288–1440.

Background and nonessential art may bleed. The 9:16 zone reserves extra space at right and bottom for variable Meta/TikTok controls and captions. Always inspect the destination preview because UI changes with placement, device, caption, and add-ons.

Use ink, paper, lime, supplied logo artwork, editorial Georgia display copy, and Arial/Helvetica utility copy. Favor one message and one action. Avoid generic AI imagery and unsupported commercial or privacy claims. Provide editable masters, web PNGs, alt text, exact copy, image provenance, and placement previews.

The full request template, platform-size caveats, source links, compliance guidance, and delivery checklist are in `docs/social-ad-asset-brief.md`.
