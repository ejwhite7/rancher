# Layout and composition

- Use a centered content width of 1240px with 48px desktop gutters.
- Major sections use approximately 100px vertical spacing.
- Favor asymmetric editorial grids with substantial negative space.
- The primary breakpoints are 1000px and 760px.
- Below 760px, reduce gutters, stack two-column sections, and place hero actions vertically.
- Use fine one-pixel divider lines to create structure without heavy containers.
- Cards are quiet warm-white surfaces with thin borders, 7px corners, and very subtle shadows.
- Avoid dense dashboard styling, glossy gradients, or excessive pills.
