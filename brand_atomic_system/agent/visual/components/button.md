# Buttons and links

## Primary button

- Dark green (`--color-ink`) fill with white text.
- One-pixel dark green border and 5px corner radius.
- Compact 14px semibold Arial label.
- Use sentence case and a clear verb phrase.
- An up-right arrow may follow the label when it communicates progression.
- Hover changes to `--color-hover` and translates upward by 2px.

## Light button

Use the lime highlight fill with dark green text for actions on dark surfaces.

## Outline button

Use a transparent background with dark green border and text for secondary actions.

## Text link

Use compact text with a quiet bottom border. Underlines and borders must remain visible without relying on color alone.

## Accessibility

All interactive controls require a visible 2px `--color-focus` focus ring with 5px offset. Preserve adequate touch size and do not encode state through color alone.
